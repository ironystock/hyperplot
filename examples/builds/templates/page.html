How this page works

Polling with a tag
Each chart polls. The server hashes its render with hx.Tag; hx.CheckPTag answers an unchanged chart with a bodiless 304, so htmx skips the swap. Charts change only when a build finishes. The summary line rides along with the daily chart as an <hx-partial>.
Filters
The form re-renders every chart with one request and innerMorph. Each pipeline pins a color slot, so it keeps its color when others are hidden.
Brush to zoom
Drag across the durations chart, or use the From/To form. The server reads the range with hx.Brushed, re-renders that window and pushes its URL, so Back undoes the zoom.
Select to drill down
Click a segment of the daily chart, press Enter on a focused day, or use the day links: the server reads the day with hx.Selected and lists its builds.
Reading the data
Hover or focus a chart and use the arrow keys, or open View as table under it.
