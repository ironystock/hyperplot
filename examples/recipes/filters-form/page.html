Filters

Change the range or the regions: one request re-renders all three charts, and each region keeps its color.

{{- /* hx-get="/" + hx-trigger="change": every change sends the whole form (range, region) to the page's own URL. hx-target="#charts" + hx-swap="innerMorph": the charts keep their ids, so htmx morphs them and the lines animate to the new data. hx-push-url="true": the address bar shows the filtered view, which can be bookmarked; Back returns to the previous one. hx-sync="this:replace": a change made while a request is in flight aborts that request and sends the form as it is now, so the last change always wins. Without it htmx queues one request and drops any later one, and on a slow link the charts, the summary and the URL would show an earlier state than the form. action="/": without script, the Apply button loads the same page. */}}

Regions {{- /* Always sent, so "nothing checked" is not a first visit. */}} {{- range .Regions}} {{- end}}
