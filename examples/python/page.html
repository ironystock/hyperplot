A live dashboard from the Python standard library

Every chart on this page is SVG drawn by a Python server that implements the hx-plot wire spec, with no Go and no framework. htmx 4 keeps the charts live; the hx-plot extension adds tooltips, keyboard reading, sliding windows, select and brush.

Latency

p50 and p95 per 10 seconds, polled every 2 seconds. Most polls are a bodiless 304. Drag across the chart to zoom, or focus it and use Shift+arrows, then Enter.
