How this page works

Polling with a tag
Latency polls every 2 s. The server hashes each render with hx.Tag, and hx.CheckPTag answers an unchanged chart with a bodiless 304, so htmx skips the swap. The KPI tiles ride along as an <hx-partial>.
Streaming
Throughput is one server-sent event stream (hx-sse:connect) that morphs the chart once a second.
Filters
The filter row re-renders every chart with one request and innerMorph. Each region pins a color slot, so it keeps its color when others are hidden.
Sizing
Resize the window: each chart re-renders at its container's width (htmx:plot:resize and hx.Size).
Brush to zoom
Drag across the latency chart, or focus it and mark a range with Shift and the arrow keys, then press Enter. The brush becomes an ordinary request (hx.Brushed); the server re-renders that range and pushes its URL, so Back undoes the zoom. The from/to form does the same without a pointer.
Select to drill down
Click a bar, or press Enter on a focused one, to open its window for that region (hx.Selected). The links under the chart open the same detail. Changing a filter returns to the live window.
Reading the data
Hover or focus a chart and use the arrow keys, or open View as table under it.
